# A Student's website
A website made for students to test their basic skills in algebra.

##Features 
* **Calculator** A user friendly calculator used for simple **BODMASS computation**
* **Test Questions** Simply used to test students response time

## Build with
* **HTML** The skeleton of the project
* **CSS** The outer view and beauty of the site
* **JavaScript** Used for computation (brain)

## How to use it
This site was made use friendly and so do not require specific skills for usage .
But for fun just try compute a false statement and see the output 😁
